# Nargis Alizai Portfolio Project

This workspace contains two portfolio versions.

## 1) Static HTML/CSS version
- File: [index.html](index.html)
- Purpose: simple one-page portfolio
- Use it for: quick preview and backup

## 2) React version
- Main files: [src/App.jsx](src/App.jsx), [src/App.css](src/App.css), [src/index.css](src/index.css)
- Purpose: modern portfolio app with reusable React structure
- Use it for: main active portfolio work

## Which one to use?

Use the React version as the main portfolio.

The static HTML page is kept as a backup/reference version.

## Run the React portfolio

```bash
npm install
npm run dev -- --host 0.0.0.0
```

Then open:

```text
http://localhost:5174/
```

## Open the static portfolio

Open this file directly in the browser:

```text
index.html
```

## Important

- Both versions are in the same project folder.
- The React version contains the latest project links and is the recommended version to keep updating.
- The HTML version is not deleted because it is a separate static backup.
